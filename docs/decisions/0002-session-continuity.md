# ADR-0002：多会话连续性协议

- 状态：accepted
- 日期：2026-07-31

## 背景

Codex 会话可能随时结束；聊天历史不是稳定的项目资产。多个会话也可能先后或并行修改项目，如果只依赖聊天摘要，容易重复工作、覆盖改动或错误报告进度。

## 决策

在项目中保存六类信息：

1. `AGENTS.md`：新会话自动读取的强制工作协议。
2. `PROJECT_STATUS.md`：只保存当前、已验证事实。
3. `TASKS.md`：稳定任务 ID、依赖和状态。
4. `docs/sessions/`：每个会话一个不可复用 ID 和独立日志。
5. `docs/claims/active/`：每个写会话一个最小文件范围 claim。
6. `docs/decisions/`：不可静默覆盖的架构决策。

提供只读的 context/check 脚本，让新会话快速建立上下文并发现 claim 范围冲突。

## 影响

- 即使聊天上下文丢失，新会话也能从项目文件恢复事实和下一步。
- 独立日志和 claim 文件减少并行编辑同一索引造成的冲突。
- 每个写会话需要承担少量记录成本。
- 协议依赖会话自觉收尾；意外中断时由下一会话按 `AGENTS.md` 的恢复流程接管。
