# 里程碑教科书

这里不是 API 参考手册，而是按照“为什么需要它 → CPU/硬件处于什么状态 → 我们
如何实现 → 如何证明它工作”的顺序，解释每个里程碑。

如果你正在第一次学习启动流程，建议先读专题文章：
[《从按下电源到 `kernel_main`：x86_64 内核启动深度讲解》](kernel-boot-deep-dive.md)。

## 每章必须回答的问题

1. 这个机制解决什么问题？没有它会怎样？
2. 进入本阶段时，CPU、内存和设备处于什么状态？
3. 关键数据结构、寄存器和地址如何关联？
4. 当前项目具体在哪些文件、函数和指令中实现？
5. 有什么可重复实验能证明实现，而不只是“看起来正确”？
6. 当前教学实现省略了什么？生产内核通常如何处理？

新章节从 [TEMPLATE.md](TEMPLATE.md) 开始。模板中的章节是里程碑 `done` 的
组成部分，不应在功能完成后长期补写。

## 图示约定

- 流程与状态变化使用 Mermaid flowchart/sequence diagram。
- 地址、栈和磁盘布局使用等宽文本图，保留精确边界。
- 图中必须区分虚拟地址、物理地址和磁盘偏移。
- 图下必须有文字解释；图不能成为唯一信息源。
- 图示必须来自当前代码常量，不得只复述预期设计。

## 拓展阅读约定

拓展阅读优先引用处理器/ABI 标准、工具官方手册、Linux/QEMU 官方文档和上游
源码。每条链接标注“用于理解什么”，并把以下内容分开：

- 基础原理：相对稳定的架构与格式规范。
- 当前主流实现：Linux、UEFI、现代 bootloader 或工具链中的工程方案。
- 项目内延伸：ADR、参考文档和后续里程碑。

外部资料可能更新；章节维护时应重新核对版本和链接。
