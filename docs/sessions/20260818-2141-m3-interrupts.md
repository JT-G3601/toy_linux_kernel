## 实际修改

- 新增 port I/O、`memcpy/memset/memmove/strlen`、COM1+VGA console、简化 formatter
  和关中断 `panic`；启动时用重叠 `memmove` 自测真实运行库行为。
- 新增 40-byte 内核 GDT、code/data/TSS selectors、64-bit TSS、`RSP0` 和独立
  16 KiB double-fault IST1；汇编执行 `lgdt/lretq/ltr` 完成内核接管。
- 新增 256-entry IDT 和 vector 0..47 stubs；统一 synthetic error code、保存
  `RAX..R15`、动态对齐 C 调用栈并通过 `iretq` 恢复。
- exception handler 输出 vector/name/error code、`RIP/CS/RFLAGS`、通用寄存器和
  page-fault `CR2`，fatal 路径诊断后 panic/halt。
- remap 8259 PIC 到 32..47，只 unmask IRQ0/1；PIT channel 0 配置为 100 Hz；
  PS/2 keyboard 转换 set-1 基本 ASCII/Shift 并回显字符。
- Make 自动构建 `KERNEL_TEST_MODE=0/1/2` 三种镜像；QEMU harness 通过 HMP FIFO
  `sendkey a` 验证真实 keyboard IRQ，并真实执行 `divq / 0` 与未映射地址读取。
- 保留损坏 stage2、非法 ELF、1 MiB low-memory 三条 M2 回归路径；所有场景继续
  使用 marker-driven 终止和 QEMU 回收。
- 新增 ADR-0006 固定 selector/vector/160-byte interrupt-frame 契约；完成
  `verified` M3 教材并同步 README、构建/启动文档和教材索引。
- 实验中发现 GDT 类型的 `aligned(16)` 会把 40-byte 表补齐为 48 bytes，改为只
  对实例对齐；自定义 formatter 不使用不匹配的宿主 `format(printf)` 检查。
- QEMU Unix monitor socket 在当前沙箱中因 bind 权限失败，改用无 socket 的
  `-monitor stdio` + 私有 FIFO，保持真实 HMP/PS2 输入链。
