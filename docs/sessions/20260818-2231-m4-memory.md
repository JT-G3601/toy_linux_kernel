## 实际修改

- 在删除 M2 identity map 前复制 `boot_info v1` 与 E820 entries；新增静态三 bitmap
  PMM，只管理 type 1 且低于 1 GiB 的完整 4 KiB frames，保留低 1 MiB 和 kernel。
- `page_alloc/page_free` 提供统计、对齐/范围/managed/ownership 检查，拒绝保留页、
  未管理页与重复释放；64 页批量压力后 free count 精确恢复。
- linker 导出 text/rodata/data/BSS section boundaries；最终页表建立 1 GiB HHDM、
  R-X/R--/RW- kernel mappings、VGA 单页 identity mapping，并删除其余低映射。
- 启用 `EFER.NXE` 与 `CR0.WP`；实现 4 KiB `vm_map/vm_unmap/vm_protect/vm_translate`、
  页表按需分配和 `invlpg`。HHDM 普通区用 2 MiB huge pages，kernel 重叠区拆为 4 KiB
  并保持 text/rodata 直映别名只读、全直映 NX。
- 新增最大 16 MiB、按页扩展的 boundary-tag first-fit heap，支持 block split、前后
  coalesce、边界 tag 校验和重复/越界释放检测；7000-byte 跨页对象读写与释放复用通过。
- 正常自测核对 kernel section 权限、旧 `boot_info` 低映射已删除、VGA 仍存在，并
  覆盖 VMM map/protect/unmap/translate。
- 扩展 `KERNEL_TEST_MODE=0..4` 和 QEMU harness：unmapped read、read-only write、NX
  instruction fetch 分别产生 `#PF error=0x0/0x3/0x11`，CR2 均为测试 virtual address。
- 新增 ADR-0007 与 `verified` M4 教材；同步 M3 教材、README、boot/build、任务和状态。
- 审查中把 PMM allocator ownership 与 reserved 状态分离，并把所有与 kernel 重叠的
  HHDM 2 MiB chunks 拆页，避免未来 kernel 增长后出现 writable text alias。

## 未完成与风险

- PMM/HHDM 只覆盖前 1 GiB；静态三 bitmap 约 96 KiB，尚无 NUMA/zone。
- VMM 不回收空中间页表，heap 不缩容；HHDM 映射 1 GiB 内 holes，但 PMM 不分配它们。
- PMM/VMM/heap 都是单核无锁实现；M5 开启 PIT 抢占前必须定义同步/关中断边界。
- VGA 仍保留一页低地址 identity mapping；console 改用 HHDM 后才能完全删除。
- M3-M4 改动尚未提交或推送；Draft PR #2 仍只覆盖 M2。
